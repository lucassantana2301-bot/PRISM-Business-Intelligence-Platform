# Política de segurança

## Versões suportadas

Apenas a última versão publicada (tag mais recente) recebe correções de segurança.

## Como reportar

Encontrou uma vulnerabilidade? **Não abra issue pública.** Use o
[reporte privado do GitHub](https://github.com/lucassantana2301-bot/PRISM-Business-Intelligence-Platform/security/advisories/new)
com o passo a passo para reproduzir e o impacto estimado.

- Confirmação de recebimento em até 3 dias úteis.
- Correção ou plano de mitigação em até 30 dias, conforme a severidade.
- Crédito no advisory, se desejar.

## Escopo

Injeção de SQL pelo Ask PRISM ou pelo Data Explorer (bypass do validador de AST e da allowlist de schema), acesso a arquivos pelo DuckDB, vazamento de chaves de provedores de LLM e exposição de dados além do dataset publicado.
